# Vision Board

This folder is the visual target aesthetic for BFI and its companies.

The SVG files are original reference cards generated for this repository. They
are not copies of Apple, OpenAI, Anthropic, Stripe, Linear, Hermes, Saint
Laurent, Loro Piana, Bottega Veneta, Tadao Ando, John Pawson, Dieter Rams, or
any other source.

## Rule for Cursor

Whenever designing any page, logo, icon, component, or layout, use the images in
`/vision-board/` as the target aesthetic. Blend the shared design language
instead of copying any single example. Maintain consistency across all BFI
companies.

## Brand targets

- BFI: quiet, academic, expensive, timeless, white space, editorial
- BR3N: black glass, AI, motion, premium software, futuristic
- OLTRE: Italian luxury, matte black, stone, architecture, sophisticated typography
- SOLGLIA: executive, data-first, clean, enterprise, precision

## Regeneration

Run:

```bash
npm run generate:vision-board
npm run generate:design-concepts
```
