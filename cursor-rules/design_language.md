# Design Language

The visual target is:

- Apple Human Interface
- OpenAI
- Anthropic
- Linear
- Stripe

Luxury references:

- Hermes
- Saint Laurent
- Loro Piana
- Bottega Veneta

Architecture and industrial design references:

- Tadao Ando
- John Pawson
- Dieter Rams

## How to use references

Use these references as principles, not assets. Do not imitate or copy any
single brand, logo, composition, or proprietary design.

For every page, logo, icon, component, animation, and layout:

1. Check `/vision-board/`.
2. Identify the relevant brand surface: BFI, BR3N, OLTRE, or SOLGLIA.
3. Blend the shared design language.
4. Preserve the parent BFI system: restraint, whitespace, typography,
   precision, and timelessness.

## Brand translation

- BFI should feel like a world-class research institution.
- BR3N should feel like a cutting-edge AI company.
- SOLGLIA should feel like premium enterprise intelligence software.
- OLTRE should feel like a modern luxury house.
