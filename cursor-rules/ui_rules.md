# UI Rules

- Build mobile-first, then desktop.
- Favor whitespace over decoration.
- Limit each screen to one primary action.
- Keep page copy short and high-signal.
- Use subtle animations in the 150-250ms range.
- Prefer editorial hierarchy over dense cards.
- Use restrained imagery or image-like art direction.
- Avoid visual clutter, loud gradients, and unnecessary iconography.
- Every interactive element needs a clear focus state.
- Preserve accessibility and readable contrast.
