# Component Rules

- Design components as reusable system parts.
- Keep brand-specific styling in tokens, accents, iconography, and imagery.
- Do not fork layout systems for BFI, BR3N, SOLGLIA, and OLTRE unless the product
  requires a different interaction model.
- Prefer simple props and semantic markup.
- Avoid one-off decorative wrappers.
- Use CSS variables for brand tokens.
- Keep motion minimal and purposeful.
