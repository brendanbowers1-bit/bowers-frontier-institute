# BFI Typography

## Master stack

- Display and wordmark: Cormorant Garamond or EB Garamond
- Interface body: Inter, Neue Haas Grotesk, SF Pro, IBM Plex Sans fallback
- Technical labels: IBM Plex Mono

## Rules

- Use no more than two families per product surface.
- Prefer large type, wide spacing, and fewer words.
- Use uppercase labels sparingly with generous tracking.
- Avoid novelty fonts and decorative effects.
- Let whitespace and hierarchy create luxury.
